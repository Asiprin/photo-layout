# photo-layout
把照片按你要的尺寸，整整齐齐排到 A4 或其他打印纸上，支持导入pdf或图片文件进行自动排版，适配移动端网页

![Snapzy_2026-10-20_15-56-14_791.png](data/attachment/forum/202610/20/155642upjmk9zngn69mmx1.png "Snapzy_2026-10-20_15-56-14_791.png")

## 用法

**四步：导入、选纸、选尺寸、导出。**

导入支持 PDF 和常见图片格式。PDF 按页转成图片，300 dpi，打印出来不糊。纸张默认 A4，也可以选 A3、Letter 或者自己填。照片尺寸内置了小 1 寸、1 寸、大 1 寸、小 2 寸、2 寸、5 寸、6 寸、7 寸，还有标准卡片 85.6×54mm，都能改毫米数。

选完它自动算一张纸能排几张。比如 2 寸在 A4 上排 25 张，1 寸能排 49 张，照片之间带裁切线，沿着剪下来就是标准尺寸。

导出的是打印就绪的 PDF，尺寸精确到毫米。也可以直接点"打印"，调起系统打印框。

所有处理都在浏览器里跑完，照片不经过任何服务器。

照片会跟着相框自动转方向。竖着的证件照想横排省纸，照片会跟着躺下排，剪完转正就行，比硬裁半张脸强。

裁切线有长虚线和四角标记两种，也可以关掉。同图铺满和多图混排都支持，后者可以几张不同照片排一张纸。

深浅色主题都有，跟着系统走。

## 安装

飞牛用户：应用中心 → 右上角"手动安装" → 选中 fpk 文件，装完桌面出现图标，点开就用。这个包 x86 和 ARM 通用

**默认端口号：3210**
